# Informations publiques recueillies (26/11/2026)

Ces informations viennent de sources publiques en ligne. **Elles ne remplacent pas la vérification du porteur** (RG-CAT-07, RG-GST-04). Elles servent à préparer les maquettes et un premier jeu de catalogue, marqué « à vérifier » tant que le porteur ne l'a pas confirmé.

Niveau de confiance :

- **Élevé** : plusieurs sources concordantes, dont une plateforme de distribution.
- **Moyen** : une seule source fiable, ou des sources légèrement divergentes.
- **Faible** : sources contradictoires.
